How to prevent XSS
  • Use textContent, not innerHTML, for user input.
  • Escape < > & " ' when building HTML on the server.
  • If you must allow HTML, clean it with a library like DOMPurify.
  • Add a Content-Security-Policy header that blocks inline scripts.
  • Set cookies to HttpOnly so scripts can't steal sessions.
Only test XSS on apps you own or are authorised to test.
